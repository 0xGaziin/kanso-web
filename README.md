# Kanso - Web Page

Landing page for [kanso-browser](https://github.com/0xGaziin/kanso-browser).

## Stack

- React / TypeScript
- Tailwind CSS

## Running locally

```bash
git clone [https://github.com/0xGaziin/kanso-web.git](https://github.com/0xGaziin/kanso-web.git)
cd kanso-web
npm install
npm run dev
```
